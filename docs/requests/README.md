# Requests to the planner

Builders and content agents file a request here when they need something outside their ownership
(a core contract change, a new dependency, a shared UI piece) or hit a decision they should not make alone.

One file per request: `YYYY-MM-DD-short-topic.md` with **What** is needed, **Why** (which spec task),
a **proposed API or answer**, and whether the requester is **blocked**. The planner answers in the same file
and deletes it once resolved.
